# Final Datasets and Analysis Scripts for Group A Rotavirus Genes

## Overview

This repository contains the finalized datasets and analytical scripts used in the study of Group A rotavirus genes.

The datasets deposited here correspond to the eleven Group A rotavirus genes analysed in the study:

- VP1
- VP2
- VP3
- VP4
- VP6
- VP7
- NSP1
- NSP2
- NSP3
- NSP4
- NSP5

The datasets represent the final data files used for the analyses reported in the associated manuscript.

## Repository Contents

### `datasets/`

This folder contains the finalized datasets used in the study. The datasets have been provided in CSV format to facilitate accessibility and reproducibility.

Each dataset corresponds to one of the eleven Group A rotavirus genes analysed in the study.

### `scripts/`

This folder contains the Python scripts developed and used for the computational analyses presented in the study.

The scripts are provided to facilitate transparency and reproducibility of the reported analyses.

## Reproducibility

The datasets and analysis scripts are deposited in this repository to allow researchers and reviewers to inspect the data underlying the study and, where appropriate, reproduce the reported computational analyses.

The deposited files correspond to the finalized datasets and analysis workflow used for the study.
